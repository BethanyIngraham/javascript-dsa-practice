# JavaScript Data Structures & Algorithms Practice

## Overview

This repository contains my practice solutions for Data Structures and Algorithms (DSA) problems implemented in **JavaScript**.

The purpose of this repository is not just to solve problems, but to **develop strong problem-solving skills, pattern recognition, and clear technical communication**, which are critical for real-world software engineering and technical interviews.

Each problem is approached intentionally, with emphasis on *why* a particular data structure or algorithm was chosen.

---

## Goals

* Strengthen core computer science fundamentals
* Practice problem-solving using JavaScript
* Learn to recognize common DSA patterns
* Improve technical communication and justification of decisions
* Prepare for technical interviews

---

## How I Practice Problems

For each problem in this repository, I follow this process:

1. **Attempt the problem independently** without external help
2. **Ask clarifying questions** (inputs, outputs, constraints, edge cases)
3. **Identify the underlying pattern or data structure**
4. Implement a clean solution in JavaScript
5. Analyze **time and space complexity (Big-O)**
6. Document my **thought process and approach** using comments and JSDoc

If I am unable to solve a problem initially, I research the concept or pattern involved and then **re-implement the solution from scratch** to ensure understanding.

## Problem File Format

Each problem file typically includes:

* Problem description
* Clarifying assumptions
* Approach explanation
* Chosen data structure or pattern
* Time complexity
* Space complexity
* Clean, readable JavaScript implementation

Example header used in solution files:

```js
/**
 * Problem: Two Sum
 * Difficulty: Easy
 *
 * Approach:
 * Use a hash map to store previously seen values
 * and check for the complement on each iteration.
 *
 * Time Complexity: O(n)
 * Space Complexity: O(n)
 */
```
